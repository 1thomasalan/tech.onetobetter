How this works

Tools enter the directory when The Tech Brief has covered them, or when they fill a gap a reader is likely to have. Inclusion is not a recommendation and nothing here is paid placement: noticed, not endorsed.

Prices, plans and claims come from each tool's own pages on the date shown. Company figures are their own claims. We haven't run hands-on tests unless a listing says so. Images are each tool's own preview image, or a plain tile.

GitHub stars count attention, not quality.

Words to know

Agent
an AI that takes steps for you, not just answers.
MCP
Model Context Protocol, the open standard that lets an AI assistant use another app.
CLI
command-line interface: a tool you run by typing in a terminal.
API
application programming interface: how software talks to other software.
Agent skill
a folder of instructions an agent loads for one kind of task.
Open source
the code is public; you can run it yourself, under its license.
